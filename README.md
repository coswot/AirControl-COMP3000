# AirControl

## Project title
AirControl: Design, Implementation and Evaluation of a
Webcam-Based Finger-Gesture Interface for Musical Interaction

## Project details
- Student: Sunchoeh Prince
- Programme: BSc Computer Science (Software Engineering)
- Module: COMP3000 Computing Project
- Institution: University of Plymouth
- Supervisor: Hai-Van Dang
- Academic year: 2026–2027

## Project vision
AirControl aims to enable musical interaction through finger gestures
and hand movements captured by a standard webcam.

The proposed application will use computer vision and a machine-learning
model trained for the project to recognise selected finger configurations
and map them to musical actions, such as triggering notes or chords.
Continuous movement will control pitch and potentially other sound
parameters.

## Current status
Project initiation and planning. The proposed functionality has not
yet been implemented or evaluated.

## Proposed technologies
- Python
- OpenCV
- MediaPipe
- A machine-learning training framework
- Audio-output and interface libraries to be selected through prototyping
